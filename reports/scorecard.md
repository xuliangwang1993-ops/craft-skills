## 各站扣分理由

### 0 需求解析
- jq 1.7 是整个库的 JSON 转接头，本站在此把一句话拆成可校验的契约；扣 0.5 分因为它只做结构化，不做语义理解（品牌中文名仍需人工确认）。
- brief 把「三个社媒尺寸」固化为 9:16 / 1:1 / 16:9，并在下游逐项验收。

### 1 素材采集
- 事实底账 16 条全部带 source_id；营业时间冲突、地址未核实、菜单缺失都显式落库，下游只能读 verified。
- 扣分：客户实拍素材为 0，官网图仅 680x510，达不到 1080p 交付标准 —— 这是本单最大的商业风险。
- crawl4ai 安装失败（见 reports/tool_verification.json），站点抓取降级为 curl + 本地解析，够用且可复现。

### 2 脚本/分镜
- 三道门：fact_ref 必须 verified、禁用词扫描、字幕行长；任何一道不过，本站直接非 0 退出。
- 因为中文名与菜单都还没到，脚本刻意不含菜名/价格 —— 这是合规，不是缺内容；客户确认后 5 分钟即可补。
- 扣分：wordcraft（Craft 家族 Windows 可执行）本机不可用，storyboard 改用 python-docx 同族思路的 PIL+手写 PDF，属降级。

### 3 切镜/调色/音频
- MLT(melt) 出时间线，ffmpeg(libx264) 出镜头；实测 melt 1088x1920 约 3.75 fps，30s 时间线约 4 分钟。
- ★ 环境坑：melt 在这台机器上对 1080 宽/1080x1080 直接段错误式失败（0 字节输出），1088x1920 才通过，所以基线画幅取 1088 再裁到 1080。
- ★ 环境坑：iOS 版 ffmpeg 没有 libx264、没有 drawtext/subtitles，只有 VideoToolbox；字幕改用 PNG 叠加（见第 5 站），CPU 版 ffmpeg 作降级。
- demucs 需要 torch，本机无 musl-aarch64 轮子 → 不可用；本片本来也没有人声/第三方音乐需要分离，缺口已记录。
- 扣分：调色用的是 ffmpeg 曲线而非 darktable（Alpine 无 darktable 包），属降级但参数可复现。

### 4 字幕
- funasr / whisper / argos-translate 三件套在本机全部装不上（torch、ctranslate2 无 musllinux-aarch64 轮子），已如实记录，没有假装跑过。
- 本片无配音，字幕来源是双语脚本，因此「ASR → 机翻 → 校对」这条链在本项目里本来就不成立；改用「脚本即真相 + 逐行核对」。
- 扣分主要在标杆性：没有可用的开源 ASR/MT 实测，属弱格，已进缺口清单。

### 5 合成
- 三尺寸各自成片（不是简单裁切）：9:16 裁 4px 边框，1:1 中心重构，16:9 模糊填充 + 竖版居中。
- 字幕用 PNG 叠加而非 subtitles 滤镜，因为 iOS 版 ffmpeg 没有 libass；外挂 srt 同时交付。
- 响度两遍法归一：测量 I=-22.16 LUFS → 目标 -14 LUFS / TP -1.5 dB（留 0.5 dB 余量抵消 AAC 编码过冲，后测真峰值才压得住 -1 dBTP）。
- ★ 成品仍是「样片」：素材是占位板 + 官网未授权图，画面里有「样片 · 占位素材 · 未授权」水印。

### 6 后测
- 后测只读第 5 站的成品，不回看中间产物 —— 与客户拿到的东西一致。
- 安全区用「行方向高频能量」定位字幕（不依赖字幕已知位置），再用红/绿框标注出图。
- CER 不适用：无口播、无可用 ASR；改用 srt 与脚本逐行零偏差作为替代指标，已如实标注。

### 7 客服
- 知识包按「能查、能答、答不了就说不确定」写：18 条 FAQ，未核实项全部显式标注。
- 自测用的是 KB 检索器（同一份 markdown），答对率 100%，但它不是生产小X，报告里已注明。
- 扣分：workbench 卡片只产出 JSON + 导入脚本，未跑真实 Supabase 环境（无凭据，且不改线上库）。
