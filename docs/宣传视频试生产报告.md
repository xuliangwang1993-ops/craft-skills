- 建议价维持任务书区间：基础包 A$300–600 + GST，月度包 A$800–1,500/月；约为外包整包 A$1,895–6,500 的 15–30%。实测机器成本可忽略，主要成本是人工校对与沟通。区间未经市场验证。
