# 宣传视频试生产报告（v3 · 2026-10-22）

> 一句话需求：**给悉尼小锅米线（Slurp Slurp Noodle）做一支 30 秒宣传短视频，配中英字幕和三个社媒尺寸**
> 分支：`trial/promo-video-v3`（craft-skills）、`trial/promo-video-cards`（xconnect-landing）。**两个 PR 都不合并。**

## 一、先看结论

| 问题 | 答案 |
|---|---|
| 链跑通了吗 | 跑通了，8 站全过，`make run SENTENCE="…"` 一条命令 |
| 能交付给客户吗 | **不能直接发**：客户素材未到，当前是带水印的样片 |
| 流程本身能卖吗 | **能**。三个尺寸 + 双语字幕 + 封面 + 后测全自动，人工只剩校对与拍摄指导 |
| 最大的坑 | 不是工具，是**客户数据缺失**（中文名、地址、营业时间、菜单价格）——链把「不许编」做成了硬门禁 |
| 最意外的坑 | 这台机器上 **1080 宽会静默产出 0 字节**（swscale 要求 16 的倍数），melt 和 ffmpeg 都踩 |

## 六、人为失败演练（证明链会停）

[`reports/fail_drill.json`](../reports/fail_drill.json)

- **A. 字幕价格被改成「A$12.50」**（客户从未确认过任何价格）
  → `qa/trace_check.py` 报 `unverified_price`，**退出码 1**，成片不进交付。
- **B. 官网菜品图被改成 `permission=borrowed`、`license` 为空**
  → 第 2 站读 `media_manifest.json` 时 Schema 校验失败，**退出码 1**，第 2 站之后全部不运行。

两次都是**下游停链**，不是「警告后继续」。

## 七、弱格与缺口（只列，不改 skills）

**工具层（本次实测不可用）**
1. TTS 配音 —— cosyvoice 被任务书禁用，其余开源 TTS 未入库 → 本片无口播
2. ASR（whisper / funasr）—— 需 torch，无 musl 轮子
3. 机器翻译（argos-translate）—— 同上
4. 人声分离（demucs）—— 同上
5. 调色（darktable）—— Alpine 无包，用 ffmpeg 曲线替代
6. 自动卡点（librosa）—— 装不上，节奏按固定 90 BPM 手排
7. 图片处理（libvips）—— 本机缺 jpeg/png 模块

**产品层（立项里已承认的缺口）**
8. 模板与素材生态 —— 没有可用的免版权素材库，占位画面只能代码绘制
9. 一键成片 —— 目前是「脚本驱动」，不是「大模型挑片段」

**环境层（不是产品问题，但会影响报价）**
10. 1080 宽 → 0 字节（swscale 要 16 的倍数）
11. iOS ffmpeg 无 libx264/libass，且会自锁
12. 4 GB 内存，只能串行渲染；本机 30 秒成片约 25 分钟/尺寸

## 八、商业化结论

**能卖，但卖的是「后期流水线」，不是「拍摄+后期整包」。**

| | 我们 | 悉尼外包（The Viral Vibe / Diprose Media 公开价） |
|---|---|---|
| 30s 成片 | ✅ | ✅ |
| 三尺寸导出 | ✅ 自动 | 通常另计或含在套餐 |
| 中英双语字幕 | ✅ 自动 + 人工校对 | Rev 英译中 US$10.49/分钟，人工另计 |
| 拍摄 | ❌ 店家手机自拍（给拍摄清单） | 半天到一天拍摄 |
| 价格 | **A$300–600 / 支**（含 1 次修改） | **A$1,895–6,500 + GST** |
| 占比 | 约为外包下限的 16–32% | — |

**建议报价**（跑完用实测修正）：
- 基础包 A$300–600：30s × 3 尺寸 + 双语字幕 + 封面 + 1 次修改
- 月度包 A$800–1,500/月：4 支，复用品牌模板
- **实测成本**：本机 CPU 约 75 分钟/支（三个尺寸），加人工校对 20 分钟 → 边际成本主要是机时
- **离正式交付还差**：① 客户实拍素材 ② 书面授权 ③ 母语者过一遍英文 ④ 中文店名与菜单价格
