# 扩库立项：底层工具库滚动扩建

> 状态：立项文档 v1 · 2026-10-22 · 依赖 PR #1（`base-layer-oss-tools`，21 个底层工具）

## 一、目标

把 craft-skills 建成一座**工具工厂**：每一个能力格子都有一个最强、可独立运行、能互相串联的工具，AI 拿到任何任务都能从格子里取工具、按「上一个输出 = 下一个输入」串成流水线，输出稳定可复现。

## 二、规则

**工厂四条：**

1. **一格一个最强工具**：同一格不放两个重复工具；
2. **全覆盖不留空格**：每个格子要么有工具，要么已立项，要么锁定闭源标杆准备重写；
3. **输出稳定**：固定版本/参数，同输入同输出，每个技能写清校验方法；
4. **输出接输入**：输出必须是标准格式（mp4/wav/png/svg/pdf/csv/json/md…），能直接喂给下一个工具。

**入选三标准：** ① 领域标杆 ② 可独立使用（命令行或 Python 直接调用，不用再包一层）③ 可对接其他工具。

**不重叠：** 不与 13 个 Craft 应用（cadcraft deckcraft designcraft effectcraft figcraft filmcraft gridcraft lightcraft pdfcraft photocraft soundcraft vectorcraft wordcraft）及 21 个已有底层工具重复。

## 三、节奏：入库一批、落地一批、立项一批，滚动推进

| 阶段 | 含义 | 进入下一阶段的标准 |
|------|------|------------------|
| **立项** | 格子已规划、工具已选定，SKILL.md 未写 | 写出 SKILL.md（frontmatter 含 `layer: base`、`backs: <格子>`；「它让我们能做什么」；安装、用法、校验、许可），合入仓库 → **入库** |
| **入库** | SKILL.md 已在仓库，按官方文档写，未实测 | ① 干净环境按文档安装成功 ② 每条示例命令实际跑通 ③ 至少一条串联测试（上游输出直接作为本工具输入、本工具输出喂给下游）通过，并修正文档 → **落地** |
| **落地** | 已安装、示例跑通、串联测试通过 | 持续回归：版本升级后重跑示例与串联测试 |

**每周一轮，每批同时前进一格：** 落地批完成验收 → 入库批开始落地 → 立项批开始写 SKILL.md → 新开下一批立项。

| 批次 | 内容 | 当前阶段 | 本轮动作 |
|------|------|---------|---------|
| 第 0 批 | PR #1 的 21 个底层工具 | 入库 → 落地中 | 实装、跑示例、串联测试 |
| 第 1 批 | 本 PR 的 22 个工具 | 入库 | 下一轮开始落地 |
| 第 2 批 | 下表 18 个格子 | 立项 | 下一轮写 SKILL.md 入库 |

## 五、验收标准（入库 → 落地）

每个工具必须全部通过：

1. **安装**：干净环境（Ubuntu + Docker 容器）按 SKILL.md 安装成功，记录版本号；
2. **示例运行**：「核心用法」每条命令实际跑通，输出通过「输入/输出校验」，跑不通的改文档；
3. **串联测试**：至少一条链路通过，例如
   - yt-dlp → ffmpeg → whisper → argos-translate → ffmpeg 烧字幕
   - pyscenedetect + librosa → mlt 自动卡点成片
   - playwright/crawl4ai → pandoc → tectonic 出 PDF
   - paddleocr → jq → duckdb → openpyxl 出报表
   - rembg → libvips → designcraft 合成海报
4. **稳定性**：同输入跑两遍，输出一致（生成类固定 seed）。

通过后把 SKILL.md frontmatter 的 `stage` 改为 `落地`。
