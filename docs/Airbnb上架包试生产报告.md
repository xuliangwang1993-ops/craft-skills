## 1. 先看这五件事

1. **平台上的照片里，7 张是小红书截图。** 带「2 of 9」和 App 水印，上下黑边。唯一一张相机原图是卫生间，而且洗手台堆着牙刷和杂物。这是 4.6 分里最容易被扣的一项，也是本次交付里唯一无法靠后期补救的一项。
2. **平台把「热水」「Essentials」标成了「无」。** 能住人的房子不可能没热水，八成是漏勾。确认前，所有文案一个字都没提。
3. **平台没有列暖气，只有空调。** 悉尼冬天夜里会冷，这是真实咨询里一定会被问到的点。文案里写成「如对冬季取暖有要求，请先确认」，没有替房东承诺。
4. **竞品数据是 0。** Airbnb 的 `robots.txt` 明确 `Disallow: /s/*/*`，搜索结果页是唯一能一次拿到同区多房源+价格的公开入口。按规则停手，没有绕。所以定价是**假设模型**，不是市场结论。
5. **链路闸门是真的。** 故意在文案里写「有暖气」、在指南里填真密码，两处都被拦下（退出码 2）。报告见 `runs/R20261022-airbnb/reports/failtest.json`。

## 4. 每站到底做了什么

**00 需求解析**：一句话 → `brief.json`（7 项交付、zh/en、双尺寸视频、40s）。用 jq 构造，不是 Python 拼字符串。

**01 采集**：curl 抓公开页（间隔 3s），解析内嵌 JSON，落 42 条事实，每条带 `source_id` 与 `verified / unverified / conflict / pending_owner` 状态。竞品 0 个，`comps.json` 写的是 `blocked_robots` 而不是伪造数据。附 `compliance.json`（两次抓取、robots 判定）和 `shot_request.md`（10 个必拍画面）。

**02 定价**：SQL 建 scenario 表算年化收入。**基准价 A$58 = 假设中位 A$68 − 共用卫浴 4 − 评分 3 − 无暖气 3**。建议：平日 A$50–65，周末约 A$70，旺季 A$90–113；最少 2 晚、旺季 3 晚、48 小时空档放 1 晚。全部标 `assumption`，`provisional: true`。

**03 照片**：去黑边 → 灰度世界白平衡 → 对比/饱和微调 → Hough 找主导竖线 → 旋转扶正（两遍）→ 4:3 裁切 → 2048 长边 → 锐化 → 打「样片」水印。**排除 2 张**：1 张与封面重复，1 张画面里有人（手持纸张遮脸，Haar 与 Apple Vision 都查不出来，靠人工抽查抓到）。参数全在 `edits.json`。

**04 视频**：每张照片排成画布（竖屏＝模糊背景 + 4:3 原图居中 + 双语字幕；横屏＝左图右文），ffmpeg `zoompan` + `xfade`，SoX 合成垫乐（CC0），`loudnorm` 到 -14 LUFS。**本机 ffmpeg worker 被中断后锁死，编码改到电脑端跑**，链路与参数不变。

**05 文案**：中英两版由同一张「段落 × 事实键」表生成，22 段全部可反查。标题 20 / 40 字符。写不进去的东西（暖气、热水、烘干机、Essentials）在文末单列「未写入」，不算卖点。

**06 指南**：WeasyPrint 出 A4 双语 PDF，16 个 `{{...}}` 占位符。含 000 / 131 444、垃圾分类（NSW 通用）、退房清单。

**07 直订站**：原生 HTML/CSS/JS，无框架、无追踪、无支付。首屏关键资源 403 KB；相册 6 图；视频带字幕；地图只到街区级（手绘 SVG，无坐标）；日历读 iCal（本轮为空，页面直说「未连接」）；表单只收姓名/日期/人数/邮箱。

**08 后测**：真实 WebView 跑 6 步（加载 / 渲染 / 语言切换 / 日历挂载 / 空表单报错 / 合法提交成功），全过；链接 0 缺失；alt 0 缺失；secret 0 命中；trace 0 不一致；静态审计 98 / 100 / 100 / 100。**Lighthouse 没跑**——本机没有 Chrome，标 `not_run`，没有拿静态分冒充。

**09 客服**：9 篇文章 + 25 条 FAQ，规则检索自测 25/25。密码、门锁码、门牌统一回「入住当天由房东发送」。

## 6. 弱格与缺口（只列，不改 skills）

1. **无动态定价数据源**（对标 PriceLabs / Beyond）——comps 为 0 时，定价只能给情景模型。
2. **无 darktable**——照片调色是 PIL/OpenCV 复刻，不是 RAW 级工艺。
3. **无 real-esrgan**——1179px 截图放大到 2048 是 Lanczos，不是超分。
4. **无已验证 TTS**（cosyvoice 在禁用名单）——视频只有垫乐，没有旁白。
5. **无 Lighthouse / Playwright**——性能与可访问性只有静态审计，不能出真实跑分。
6. **无搜索意图→房源的公共数据入口**——robots 一挡，竞品分析就断，这是结构性的。
7. **规则检索 ≠ RAG**——知识包自测 100% 是规则命中，接小助手后建议换向量检索。
8. **直订站没有预订引擎**——不收款、不锁房、不发确认信，只是申请表。

## 7. 商业化：能省多少、能卖多少

**平台费**：Airbnb 单一费率模式约 15.5% + GST ≈ **17.05%**。
按本次建议价 A$58 / 晚、平均 2 晚一单：
- 每单平台费 ≈ A$19.8；**直订 10 单 ≈ 多留 A$198**；
- 若一年 60 单（约 55% 入住率），平台费 ≈ A$1,188；直订把这笔变成房东收入（扣除约 1.75% 收款手续费）。

**建议报价（未经验证，按实测工时修正）**

| 包 | 内容 | 建议价 |
|---|---|---|
| 自家试点 | 本房源全套，作为案例与模板 | 免费（已记录实测工时 ≈ 4.5 小时，其中 2 小时是工具踩坑） |
| 对外基础包 | 精修照片 + 双尺寸视频 + 中英描述 + 入住指南 PDF | **A$400–800** |
| 直订站 + 客服 | 站点 + 知识包 + 上线陪跑 | **一次性 A$800–1,500 + 月维护 A$50–100** |

对比：本地短租摄影 + 视频对外报价 A$280–1,299（domainpix）。我们替代的是**后期 + 文案 + 指南 + 站点 + 客服**，拍摄仍由房东手机完成。

**能不能卖**：基础包能卖，但要先解决两件事——(1) 照片必须房东原图，(2) 定价必须先补 10–20 个竞品。直订站能演示，离「能收钱」还差预订引擎与取消政策文本。
